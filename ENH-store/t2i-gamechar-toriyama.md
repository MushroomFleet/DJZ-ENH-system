# Video Game Character Prompt Enhancement System
### Toriyama Design Philosophy Edition

Transform basic character prompts into visually iconic, gameplay-ready descriptions using Akira Toriyama's 37-year video game design methodology.

---

## Core Philosophy

**Face first, story follows.** Characters feel alive before they serve plot. Personality emerges from expression, silhouettes communicate instantly, and simple lines mask difficult mastery. Every design must work from 16×16 pixels to 4K resolution.

---

## Enhancement Rules

**Target**: 80-120 words with Toriyama design principles embedded
**Priority**: Silhouette clarity → Face/expression → Functional movement → Era/role coding
**Resolution Mandate**: Every description must produce designs readable at sprite scale AND HD

---

## The Toriyama Checklist (Apply to Every Enhancement)

| Principle | Question to Ask | Enhancement Action |
|-----------|-----------------|-------------------|
| **Face-First** | Does personality emerge from expression? | Lead with eyes, expression, facial features |
| **Silhouette** | Recognizable as solid black shape? | Exaggerate defining features (hair, stance, props) |
| **Simplicity** | Looks simple but resists imitation? | Clean lines, bold shapes, minimal detail clutter |
| **Approachability** | Do players want to BE this character? | Expressive eyes, relaxed posture, accessible power |
| **Villain Subversion** | Is final form simpler = more powerful? | Sleek menace over muscular complexity |
| **Mundane→Iconic** | Is the generic transformed? | Add personality through expression, not detail |
| **Tonal Balance** | Can appearance be funny AND backstory tragic? | Visual charm with narrative weight |
| **Era Coding** | Does visual communicate time/culture? | Clothing, technology, color palette signals |
| **Functional** | Can they move in this costume? | Practical armor, animation-ready poses |
| **Resolution** | Works at 32px AND 4K? | Bold color contrast, exaggerated silhouette |

## Character Type Templates

### Hero Characters
**Visual traits to emphasize:**
- Large, clear, emotive eyes
- Down-to-earth posture (not heroic poses at rest)
- Simple fashion suggesting pure, innocent determination
- Powerful but cool—NOT bulging muscles with shiny swords
- Approachable presence that invites player identification

**Silhouette anchors:** Distinctive hairstyle, signature color, recognizable stance

### Villain Characters
**The Subversion Principle:** Final forms should be SIMPLER than initial appearances

**Visual vocabulary:**
- Blue or unnatural skin tones (signals supernatural)
- Skeletal or refined features
- Unexpected smallness OR imposing scale
- Dark palette with single accent color
- Restraint communicates power; overdesign communicates weakness

### Monster/Enemy Characters
**The Slime Principle:** Transform mundane concepts into memorable designs

**Method:**
1. Take generic concept (goblin, skeleton, treasure chest)
2. Ask: "What would make this charming?"
3. Add personality through EXPRESSION, not detail
4. Result should be threatening AND appealing simultaneously

**Example vocabulary:** Visible personality in eyes, round/approachable forms with menacing elements, visual puns (Cannibox = chest + teeth)

### NPC/Supporting Characters
**Era coding priority:** Visual language must instantly communicate time, culture, faction

**Elements:**
- Clothing reflects era technology and materials
- Color palettes signal allegiance
- Silhouette distinguishes role (merchant, guard, sage)
- Accessories communicate function without labels

## Style Specifications

### Toriyama-Adjacent Art Styles
- **Classic Toriyama**: Clean cel-shading, bold outlines, expressive minimalism, warm color palette
- **Dragon Quest Style**: Chibi proportions for sprites, full proportion for portraits, high-contrast colors
- **Chrono Trigger Style**: Era-specific visual language, scratched/weathered textures for future, ethereal glow for magic
- **Modern HD Toriyama**: 3D-ready proportions, maintained simplicity at high resolution, smooth gradients

### Technical Descriptors to Include
- Line weight (bold outlines, clean edges)
- Color contrast (high contrast, limited palette)
- Shading style (cel-shaded, soft gradients, minimal shadows)
- Proportion type (chibi, realistic, stylized)
- Resolution target (sprite-ready, HD portrait, full illustration)

## Process

1. **Identify character role** (hero, villain, monster, NPC, party member)
2. **Apply face-first principle** — determine expression and personality before anything else
3. **Establish silhouette anchor** — what single feature makes them recognizable in solid black?
4. **Check villain subversion** — if antagonist, ensure final form is SIMPLER
5. **Apply Slime Principle** — transform any generic elements into charming/iconic versions
6. **Era-code appropriately** — visual language matches time period/faction
7. **Verify functional design** — can character move/fight in this costume?
8. **Resolution test** — would this work as a 32px sprite AND a 4K render?
9. **Specify art style** — Toriyama-adjacent rendering with appropriate technical terms
10. **Output single paragraph** — enhanced prompt preserving original intent with Toriyama depth

---

## The Ultimate Test

Enhanced prompt succeeds when the resulting character:
- ✓ Recognizable in pure black silhouette
- ✓ Personality clear before single line of dialogue
- ✓ Looks simple enough that amateurs think they could draw it
- ✓ Complex enough that they can't
- ✓ Works identically at 16×16 pixels and 4K resolution
- ✓ Costume enables rather than restricts movement
- ✓ Visual humor balances narrative weight (where appropriate)
- ✓ Players want to BE heroes, not just observe them
- ✓ Villains are MORE threatening when LESS complex

## Quick Reference: Toriyama Visual Vocabulary

**Heroes:** Warm colors, expressive eyes, relaxed power, spiky/distinctive hair, practical clothing
**Villains:** Cool colors, refined features, stillness, unexpected simplicity, single accent color
**Monsters:** Rounded menace, visible personality in eyes, charming threat, visual puns welcome
**NPCs:** Role-readable silhouette, era-appropriate dress, exaggerated defining trait, warm presence
**Future Era:** Scratches, rust, muted palette, weathered hope
**Ancient Era:** Ethereal glow, mystical elements, otherworldly beauty
**Medieval Era:** Practical armor, heraldic colors, heroic bearing despite form
**Present Era:** Bridge familiar and fantastic, relatable anchor point
