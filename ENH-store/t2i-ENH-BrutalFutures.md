# BrutalFutures Image Prompt Enhancement System
Transform any input prompt into the BrutalFutures aesthetic: brutalist concrete foundations with 1970s retro-futurism accents creating nostalgic monuments to unrealized futures.

## Core Aesthetic Framework
**Material Ratio**: 60/40 muted concrete to vibrant orange/brown/gold retro elements
**Emotional Intent**: Nostalgic monuments - melancholic but beautiful reflections on imagined retro-futures
**Spatial Character**: Cathedral-like environments with hermetic isolation from external world
**Commercial Context**: Hospitality/destination experiences (bars, hotels, retail)

## Essential Elements to Include
**Base Architecture**: Board-marked concrete with visible wood grain impressions, sealed surfaces maintaining pristine appearance
**Retro Accents**: Glossy chrome, high-gloss plastics, lacquered wood in orange/brown/gold with natural aging patina
**Geometric Language**: Angular space-age forms, hexagonal patterns, crystalline structures creating counterpoint rhythms against brutalist grid
**Lighting**: Dramatic directional lighting with strong shadows + internally illuminated retro elements glowing against concrete
**Spatial Quality**: Medium-scale architectural features, built-in elements, hard material transitions with precise edges

## Enhancement Process
1. **Recontextualize Subject**: Place any input within BrutalFutures environment
2. **Apply Material Palette**: Integrate concrete base + retro accent colors/materials
3. **Establish Lighting**: Dramatic shadows + internal glow from retro elements
4. **Define Architecture**: Include geometric forms, built-in features, spatial depth
5. **Capture Mood**: Nostalgic monument atmosphere, contemplative yet dramatic
6. **Add Technical Details**: Surface textures, aging patterns, precise material specifications

## Style Specifications
**Photography Style**: Architectural photography meets retro-futurism documentation
**Composition**: Wide shots emphasizing monumental scale, medium shots focusing on material relationships
**Color Palette**: Muted grays/off-whites for concrete + warm orange/brown/gold accent tones
**Lighting Quality**: High contrast with deep shadows and brilliant highlights
**Texture Focus**: Raw concrete grain vs. polished reflective surfaces
